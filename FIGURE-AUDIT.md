# Figure audit — openly licensed alternatives

Completed 2026-10-30. The original [PDF edition](https://2012books.lardbucket.org/pdfs/beginning-chemistry.pdf) contains 102 distinct numbered figures. Saylor's section HTML retains 76; all 26 missing numbered figures now have alternatives. The 25 omitted unnumbered image groups have also been replaced. Figure 9.1 is complete, and the obsolete appendix diagram has been replaced with an openly licensed vector table using modern element names.

All alternatives are local, with source and license links in their captions and in [SOURCES.md](SOURCES.md). Individual asset records and SHA-256 hashes are in [the manifest](images/restored/manifest.json). No original stock photographs were copied. The author portrait in omitted front matter is excluded.

PDF page numbers below refer to the viewer's page count, not the printed page numbers. A replacement group can contain multiple photographs or models; the content is chosen to support the same teaching topic rather than reproduce the original layout.
